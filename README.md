# Personal Portfolio

웹디자인과 프론트엔드 프로젝트를 소개하는 개인 포트폴리오 사이트입니다.

## 주요 섹션

- Hero
- About
- Skills
- Projects
- Project Detail
- Experience
- Contact

## 대표 프로젝트

### LullyDay

React와 Firebase를 활용해 제작한 감성 라이프스타일 쇼핑몰 포트폴리오입니다.

주요 기능:

- Firebase Google Login
- Firestore 상품 CRUD
- 관리자 이메일 접근 제한
- 장바구니 기능
- 검색 기능
- 다크모드
- Vercel 배포

## 사용 기술

- React
- Vite
- Framer Motion
- CSS
- Vercel
